Select a file in Explorer, press **Ctrl + Alt + Space**, and choose an action. Save a photo as PNG or JPG, extract audio from a video, trim a track, unpack an archive, or turn PDF pages into images.

The circle adapts to your selection. Previews, settings, progress, and results stay close to the file. Open the full window when you want to work with a batch.

**Windows 10/11 x64 · Local processing · Light and Liquid Glass themes**

## What you can do

| Work with | Tools |
| --- | --- |
| **Images** | Save as JPG, PNG, BMP, TIFF, GIF, or ICO; export SVG with an embedded image. WebP and AVIF are also available. Compress, resize, crop, rotate, flip, add text or logo watermarks, remove metadata, build contact sheets, and assemble images into a PDF. |
| **Video** | Export MP4 or WebM, resize and compress, remove audio, extract a soundtrack, save PNG frames, create a GIF, and trim a time range. |
| **Audio** | Convert MP3, WAV, FLAC, M4A/AAC, Opus, and Ogg/Vorbis; trim, adjust volume and fades, normalize loudness, edit tags, and extract cover art. |
| **PDF & OCR** | Export pages as PNG/JPG; merge, select, reorder, rotate, or split pages; extract text and embedded images; optimize PDFs; recognize Russian and English text. |
| **Archives & folders** | Create ZIP, TAR, TAR.GZ, or 7z; browse and extract archives or selected entries; create 7z archives with a password. |
| **File tasks** | Generate and verify SHA-256 checksums, inspect file and media details, and batch-rename files with a preview and undo. |
| **Links** | Download video or audio as MP4/MP3, then convert or trim the saved file. Paste a link or use the browser's address bar. |

## Made for everyday work

- **Call it where you need it.** Select files or folders in Explorer or on the desktop and use your chosen shortcut.
- **Paste and continue.** Ctrl + V loads a copied file or link. Convert, Save as, Copy, Trim, and More keep the file in the center.
- **Trim visually.** Drag the A/B boundaries or enter exact times. Listen to the range before saving it.
- **Keep the queue under control.** Follow progress, pause the next tasks, resume, or cancel. The tray keeps the controls nearby.
- **Reuse your settings.** Save presets, pin favorites, repeat an operation, or combine image tools into a short chain.
- **Get to the result.** Open it, reveal it in Explorer, copy the file or path, or compare an image with its original.
- **Make it yours.** Choose Crimson Noir glass or the light theme, change the circle size, reduce transparency, and reorder sectors.

## Get started

1. Run **Arclo.exe**. No installation or separate .NET runtime is needed.
2. Select a file in Explorer and press **Ctrl + Alt + Space**. You can also choose files inside Arclo or drag them into the circle.
3. Pick an action. Additional processing components are available through links inside the app when needed.
4. Find the new file beside the original or in your chosen output folder.

| Shortcut | Action |
| --- | --- |
| Ctrl + Alt + Space | Show or hide the circle; configurable in settings |
| Ctrl + O / Ctrl + Shift + O | Choose files / folders |
| Ctrl + V | Load a copied file or link |
| Ctrl + K | Search tools |
| Esc / right-click | Close a card or hide the compact menu |
| Left / Right, Enter | Select and activate a radial action |

Settings, history, presets, and built-in components are stored in **`%LOCALAPPDATA%\Arclo`**.
