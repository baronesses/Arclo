# Arclo identity and interface

Arclo is the new name of the Windows file toolkit previously developed as Orbit. The rename retains version **0.32.0** and existing user settings.

## Original identity

The owner supplied both original assets. They are preserved without retouching:

- [Logo, PNG](assets/arclo-logo.png) — the temporary glossy crimson emblem.
- [Wordmark, SVG](assets/arclo-wordmark.svg) — the custom lettering for the name.

<img src="assets/arclo-logo.png" width="160" alt="Original Arclo emblem">

The application uses the supplied emblem for its window, tray, executable, and header. The header reproduces the SVG's letter geometry as native WPF vectors, with ink that follows the selected theme. The GitHub banner uses the original SVG paths and gradients on a dark background.

## Interface

- **Liquid Glass / Crimson Noir:** dark glass, pearl lettering, and crimson accents.
- **Light:** pale surfaces and dark text.
- The compact circle adapts its actions to the current file. Tool cards, progress, and results stay near that file.
- Existing options include reduced transparency, high-contrast fallback, circle size, and supported sector reordering. An external skin marketplace or skin-file format is not included.

The screenshots in the README are actual renders of the renamed 0.32.0 executable, using owned diagnostic fixtures. They are not interface mockups. Full-window images show the new identity; compact mode omits the header to preserve working space.

The interface is currently primarily Russian. English and Russian documentation does not imply a complete English UI translation.
