# Third-party components in the local Arclo preview

Arclo 0.32 retains the downloader introduced in Orbit 0.29: **yt-dlp 2026.10.21** from its [official Windows release](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.21) and **Deno 2.9.8** from its [official Windows x64 release](https://github.com/denoland/deno/releases/tag/v2.9.8). Both were checked against upstream release SHA256 digests. The yt-dlp standalone contains yt-dlp-ejs 0.8.0; Deno is the bundled external JavaScript runtime. The Windows PyInstaller executable is distributed under GPLv3-or-later with third-party notices; its matching source archive is included. Deno uses MIT with bundled dependency notices. `tools/download-tools-provenance.json` records pinned assets, versions, digests and packaged files; `tools/DOWNLOAD-TOOLS-ORIGIN.md` describes source origins and license files. `scripts/Copy-DownloadTools.ps1` performs an offline, hash-checked copy and refuses to replace different runtime files.

These native components were copied from the existing local development environment or extracted from identified upstream release assets to make the private test folder usable without separate installation. They are unmodified. This file identifies their provenance; it is not a claim that public redistribution packaging has been audited.

- **ImageMagick7.1.2-21**, from the locally installed `ImageMagick-7.1.2-Q16-HDRI` package. Original License.txt and NOTICE.txt are kept beside magick.exe. Project: https://imagemagick.org/ . Source release: https://github.com/ImageMagick/ImageMagick/tree/7.1.2-21 .
- **FFmpeg6.0 essentials, www.gyan.dev**, static GPLv3 build. Original LICENSE and README.txt are kept beside ffmpeg.exe/ffprobe.exe. The supplied README identifies source commit https://github.com/FFmpeg/FFmpeg/commit/ea3d24bbe3 and lists build configuration and external libraries. Project: https://ffmpeg.org/ .
- **Poppler26.07.0**, package `poppler=26.07.0=h6618ce5_3` from the existing Codex dependency runtime. Its manifest.json is preserved; bundled Library/bin DLLs and share/poppler data retain the package layout. Project and source: https://poppler.freedesktop.org/ and https://gitlab.freedesktop.org/poppler/poppler/-/tree/poppler-26.07.0 . Upstream Poppler uses GPLv2-or-later; its packaged dependency DLLs have their own licenses. The stripped local runtime did not include a complete per-dependency license/source set; review and complete that set before public distribution.
- **Microsoft .NET9.0.18 runtime and Windows Desktop runtime**, from the local NuGet runtime packs. Available LICENSE and THIRD-PARTY-NOTICES files are copied under licenses/.
- **Poppler26.07.0 extraction utilities**, unmodified `pdftotext.exe` and `pdfimages.exe` from the matching conda-forge package `poppler-26.07.0-h6618ce5_3.conda`: https://conda.anaconda.org/conda-forge/win-64/poppler-26.07.0-h6618ce5_3.conda . Package SHA256 `3fdbb4caf50ecae4fa447cb7a7d6d5b521a39ae8d4de4f6565e0ce9cd6d7f903` was checked against the upstream package metadata. `tools/poppler/EXTRACTION-ORIGIN.json` records source and exact utility hashes; `extraction-licenses/COPYING` preserves the package's GPL-2.0-or-later notice. Existing same-package DLLs and data are retained.
- **qpdf12.4.2**, unmodified portable Windows x64 runtime from the official release https://github.com/qpdf/qpdf/releases/tag/v12.4.2 . The official ZIP SHA256 was verified as `db87077e683630c1217e0e8f9a20a9749d952ab676e881c3689187763a5de25d`. Only runtime files and their licenses/notices are included under tools/qpdf; ORIGIN.json records the download and individual runtime hashes. qpdf uses Apache-2.0; the official copyright notice also identifies its packaged dependencies.

- **Tesseract5.5.0.20241111 Windows x64**, runtime extracted without installation from the Windows installer asset hosted by the upstream release https://github.com/tesseract-ocr/tesseract/releases/tag/5.5.0 . Exact asset: https://github.com/tesseract-ocr/tesseract/releases/download/5.5.0/tesseract-ocr-w64-setup-5.5.0.20241111.exe . The dependency DLLs are unmodified MSYS2 runtime components from that installer. Only the runtime dependency closure is included under tools/tesseract; licenses/ contains upstream component notices. **English and Russian tessdata_fast** models come from https://github.com/tesseract-ocr/tessdata_fast . tools/tesseract/ORIGIN.json pins model revisions, exact download URLs and measured SHA256 hashes; it distinguishes measured hashes from independent publisher digests. Tesseract and tessdata_fast use Apache-2.0; bundled native dependencies have their own licenses.

- **7zr.exe 26.04 (2026-10-05), x86**, the unmodified reduced standalone 7-Zip console executable from the official download page https://www.7-zip.org/download.html and its linked asset https://github.com/ip7z/7zip/releases/download/26.04/7zr.exe . Measured SHA256: `256feca8e274e5da655e2a284fabafd9f554365eb164862089dacd4e8276d282`. The binary identifies itself as public domain; the matching official Extra README explicitly confirms the public-domain status of 7zr.exe. The original Extra README/license are included as reference notices, together with an explanatory LICENSE.txt and ORIGIN.json under tools/7zip. No other Extra executable or DLL is bundled. Source: https://github.com/ip7z/7zip/tree/26.04 . The x86 executable runs through Windows x64 WoW64; Arclo itself remains x64.

Arclo's application source-code license has not yet been selected by its owner. The public repository currently presents the application and original branding; the full native-tool ZIP is not publicly released.
